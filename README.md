# Симбиоз

Браузерный рогалик об аватаре шести стихий: огонь, вода, земля, воздух, металл и дерево.
Смешивай стихии, навыки и симбиозы, переживи 24 волны и победи Пожирателя Стихий.

**Играть:** https://tsenze13.github.io/Simbioz/

Можно и без интернета: скачать `index.html` и открыть в браузере двойным кликом.

## Управление
WASD — движение · Пробел — рывок · 1–5 — навыки · R — ульта · Z–N — предметы ·
T — древо навыков · E — торговец · P — пауза
Alt + клавиша навыка (или правый клик по слоту) — автоприменение навыка. Огнемёт — удерживать клавишу.

## Для разработки
- Исходники в `src/`, игра собирается в один файл: `python3 build.py`
- Автотест: `python3 tests/smoke.py` (нужен `pip install playwright`)
- Подробная карта кода — в `CLAUDE.md`
